# City Bus Management System

A Java-based City Bus Management System developed as part of my Software Engineering studies.

## About the Project

This project is designed to manage the main components of a city bus system, including buses, routes, drivers, passengers, and tickets.

## Features

- Bus management
- Route management
- Driver management
- Passenger management
- Ticket management
- Java-based object-oriented programming

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- IntelliJ IDEA

## Project Structure

The project contains separate Java classes for:

- Bus
- Route
- Driver
- Passenger
- Ticket
- City Bus Management System

## What I Learned

Through this project, I practiced:

- Java classes and objects
- Encapsulation
- ArrayLists
- Object-oriented programming
- Organizing a multi-class Java application
- Problem solving and program design
